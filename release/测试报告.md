## 四、修复的 Bug（测试中发现并修复）

1. **商城免费商品购买失败**：`UPDATE coins=coins-0` 的 affected_rows 返回 0（MySQL 默认只计"值变化行"）→ 给 mysql_real_connect 加 `CLIENT_FOUND_ROWS` 标志，让 affected_rows 返回匹配行数。已重编验证 PASS。
2. **客户端证书固定失效**：Windows PowerShell 管道破坏 DER 二进制，导致 `openssl x509 -outform DER | openssl dgst -sha256` 算出错误指纹；改用 `openssl x509 -fingerprint -sha256` 得到正确值 `5a0c5b93...`，写入白名单后 TLS 握手 PASS。
3. **服务端 Windows 跨平台网络层**：epoll 专属代码改造为 Winsock2 + select（100ms 轮询），Linux 分支原样保留。
4. **MySQL 客户端类型跨平台**：`MYSQL_BIND.is_null` 在 Oracle MySQL8 是 bool*、MariaDB 是 my_bool*，用 `std::remove_pointer_t<decltype(MYSQL_BIND::is_null)>` 自动适配，两端都能编。
5. **历史编译修复**（前序轮次）：TcpConnection 命名空间统一、Buffer 改名 NetBuffer、C++17 升级、LoginWindow 缺失槽实现。

## 五、已知限制

1. **服务端 select 实现**：Windows 版用单线程 select + 100ms 轮询（功能等价但性能低于 Linux epoll）。长时间高频测试后偶发响应卡顿，重启服务端即恢复。本地测试/演示足够，生产环境请用 Linux 服务端。
2. **登录锁定按 IP 计数**：设计文档要求"5 次失败锁 15 分钟"，当前实现按 IP+用户名双维度，同一 IP 下某用户失败会累加到 IP 维度。测试脚本每轮前清理 login_fail:* key 保证可重复。
3. **新用户金币=0**：商城商品需金币购买，新用户默认 0 金币需通过对局奖励或手动充值才能购买付费商品（免费商品 price=0 可直接购买）。
4. **自签证书**：客户端跳过标准 CA 校验改用指纹固定，仅适用于本地/内网测试；公网部署请换正式证书。
