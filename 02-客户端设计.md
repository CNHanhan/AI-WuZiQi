# 客户端设计文档 — AI-WuZiQi Qt Client

> 版本：v1.0 | 日期：2026-05-18

---

## 一、总体设计

客户端基于 **Qt Widgets（或 Qt Quick QML）** 开发，采用 **MVC 架构**。

### 1.1 技术选型

| 模块 | 技术 |
|------|------|
| UI框架 | Qt 6.5 Widgets / QML |
| 网络 | Qt Network (QTcpSocket + QSslSocket) |
| 序列化 | QJsonDocument |
| 本地存储 | QSettings (配置文件) / SQLite (本地缓存) |
| 图形渲染 | QPainter (棋盘) / OpenGL (特效) |
| 加密 | OpenSSL (调用 C++ 服务端相同库) |

### 1.2 模块划分

```
Client Application
├── UI Layer (界面层)
│   ├── LoginWindow        # 登录/注册窗口
│   ├── MainWindow         # 主窗口（大厅）
│   ├── RoomWindow         # 房间窗口
│   ├── GameWindow         # 对局窗口
│   └── ShopWindow         # 商城窗口
├── Network Layer (网络层)
│   ├── TcpClient          # TCP/SSL 客户端封装
│   └── ProtocolCodec      # 协议编解码
├── Game Logic Layer (游戏层)
│   ├── GameController     # 游戏流程控制
│   ├── GomokuBoard        # 棋盘逻辑
│   └── AIManager          # 离线AI管理
├── Data Layer (数据层)
│   ├── UserManager        # 用户数据管理
│   └── ConfigManager      # 配置管理
├── Crypto Layer (加密层)
│   └── CryptoManager      # 加解密/签名
└── Security Layer (安全层)
    ├── InputValidator      # 输入验证
    ├── SecureStorage       # 安全存储（Windows Credential Manager）
    └── CertificatePinner   # 证书固定
```

**心跳机制：** 每 30 秒发送一次心跳包，超过 90 秒未收到响应则判定断线重连。

**棋盘控件（GomokuBoardWidget）核心绘制逻辑：**

```cpp
void GomokuBoardWidget::paintEvent(QPaintEvent* event) {
    QPainter painter(this);
    painter.setRenderHint(QPainter::Antialiasing, true);

    // 1. 绘制棋盘背景（木质纹理或皮肤）
    drawBoardBackground(painter);

    // 2. 绘制网格线（15x15）
    drawGridLines(painter);

    // 3. 绘制星位（天元等5个点）
    drawStarPoints(painter);

    // 4. 绘制棋子
    for (int i = 0; i < 15; ++i) {
        for (int j = 0; j < 15; ++j) {
            if (board_.get(i, j) != 0) {
                drawStone(painter, i, j, board_.get(i, j));
            }
        }
    }

    // 5. 绘制最后落子标记
    drawLastMoveMarker(painter);

    // 6. 绘制落子特效（如果有的话）
    drawEffect(painter);
}
```

### 2.5 离线 AI 对战

class AIManager : public QObject {

**AI 线程设计：** AI 计算放在独立线程，避免界面卡顿；计算完成后通过信号通知 UI 层落子。

## 三、客户端构建

### 3.1 Qt 项目文件（AI-WuZiQi.pro）

```qmake
QT += core gui network ssl

greaterThan(QT_MAJOR_VERSION, 4): QT += widgets

TARGET = AI-WuZiQi
TEMPLATE = app

SOURCES +=     src/main.cpp     src/network/tcpclient.cpp     src/ui/loginwindow.cpp     src/ui/mainwindow.cpp     src/ui/gamewindow.cpp     src/game/gamecontroller.cpp     src/game/gomokuai.cpp     src/shop/shopmanager.cpp     src/crypto/cryptomanager.cpp

HEADERS +=     include/network/tcpclient.h     ...

RESOURCES +=     resources/resources.qrc
```

### 3.2 打包发布（Windows）

使用 **windeployqt** 打包依赖：

```bash
windeployqt AI-WuZiQi.exe --release
```

再用 **Inno Setup** 或 **NSIS** 制作安装包。
