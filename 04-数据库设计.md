## 一、数据库选型

- **主库：** MySQL 8.0（InnoDB 引擎，支持事务）
- **缓存：** Redis（Session、排行榜、房间状态）

## 三、详细表结构

### 3.1 用户表（t_user）

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| uid | BIGINT UNSIGNED | PK, AUTO_INCREMENT | 用户唯一ID |
| username | VARCHAR(32) | UNIQUE, NOT NULL | 用户名 |
| password_hash | VARCHAR(128) | NOT NULL | Argon2id 哈希值 |
| salt | VARCHAR(32) | NOT NULL | 盐值 |
| email | VARCHAR(64) | UNIQUE, NOT NULL | 注册邮箱 |
| avatar | VARCHAR(32) | DEFAULT 'default' | 头像标识 |
| coins | BIGINT | DEFAULT 0 | 金币余额 |
| elo_score | INT | DEFAULT 1500 | ELO积分 |
| wins | INT | DEFAULT 0 | 胜场 |
| losses | INT | DEFAULT 0 | 负场 |
| draws | INT | DEFAULT 0 | 和局 |
| total_games | INT | DEFAULT 0 | 总对局数 |
| status | TINYINT | DEFAULT 1 | 状态(0=封禁,1=正常) |
| reg_time | DATETIME | NOT NULL | 注册时间 |
| last_login_time | DATETIME | | 最后登录时间 |
| login_attempts | INT | DEFAULT 0 | 连续登录失败次数 |
| lock_until | DATETIME | | 锁定截止时间 |

**索引：**
- INDEX idx_username (username)
- INDEX idx_email (email)
- INDEX idx_elo (elo_score)

```sql
CREATE TABLE t_user (
    uid BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(32) NOT NULL UNIQUE,
    password_hash VARCHAR(128) NOT NULL,
    salt VARCHAR(32) NOT NULL,
    email VARCHAR(64) NOT NULL UNIQUE,
    avatar VARCHAR(32) DEFAULT 'default',
    coins BIGINT DEFAULT 0,
    elo_score INT DEFAULT 1500,
    wins INT DEFAULT 0,
    losses INT DEFAULT 0,
    draws INT DEFAULT 0,
    total_games INT DEFAULT 0,
    status TINYINT DEFAULT 1,
    reg_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    last_login_time DATETIME,
    login_attempts INT DEFAULT 0,
    lock_until DATETIME,
    INDEX idx_elo (elo_score)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 3.2 对局记录表（t_game_record）

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| record_id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | 记录ID |
| room_id | BIGINT UNSIGNED | NOT NULL | 房间ID |
| black_uid | BIGINT UNSIGNED | NOT NULL | 黑方UID |
| white_uid | BIGINT UNSIGNED | NOT NULL | 白方UID |
| winner_uid | BIGINT UNSIGNED | | 胜者UID（NULL=和局） |
| end_reason | TINYINT | | 结束原因(1=五连,2=和棋,3=认输,4=超时) |
| black_time_used | INT | | 黑方用时（秒） |
| white_time_used | INT | | 白方用时（秒） |
| moves_json | TEXT | | 棋谱（JSON数组，用于复盘） |
| start_time | DATETIME | NOT NULL | 开始时间 |
| end_time | DATETIME | NOT NULL | 结束时间 |

```sql
CREATE TABLE t_game_record (
    record_id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    room_id BIGINT UNSIGNED NOT NULL,
    black_uid BIGINT UNSIGNED NOT NULL,
    white_uid BIGINT UNSIGNED NOT NULL,
    winner_uid BIGINT UNSIGNED,
    end_reason TINYINT,
    black_time_used INT,
    white_time_used INT,
    moves_json TEXT,
    start_time DATETIME NOT NULL,
    end_time DATETIME NOT NULL,
    INDEX idx_black (black_uid),
    INDEX idx_white (white_uid),
    INDEX idx_start_time (start_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 3.3 商城商品表（t_shop_item）

| 字段名 | 类型 | 约束 | 说明 |

### 3.6 排行榜缓存（Redis）

```
# 键设计
rank:elo           # ZSET，value=uid，score=elo_score
rank:wins          # ZSET，value=uid，score=wins

# 用户信息缓存（Hash）
user:{uid}        # {username, elo_score, wins, avatar, ...}

# 在线状态
online:{uid}      # STRING，TTL=90s（心跳续期）

# 房间信息
room:{room_id}    # HASH，存储房间状态
```

### 3.7 会话管理（Redis）

会话信息仅存储在 Redis 中，不持久化到数据库：

```
# 会话键设计
session:{token}   # STRING，value=uid，TTL=7200s（2小时）

# 登录失败记录
login_fail:{ip}   # STRING，value=失败次数，TTL=900s（15分钟）
login_fail:{username}  # STRING，value=失败次数，TTL=900s（15分钟）
```

### 3.8 安全审计日志表（t_security_log）

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| log_id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | 日志ID |
| uid | BIGINT UNSIGNED | | 用户ID（登录失败时为NULL） |
| ip | VARCHAR(45) | NOT NULL | 客户端IP |
| action | VARCHAR(32) | NOT NULL | 操作类型(login/password_change/buy等) |
| status | TINYINT | NOT NULL | 状态(0=失败,1=成功) |
| details | TEXT | | 详细信息 |
| create_time | DATETIME | NOT NULL | 创建时间 |

```sql
CREATE TABLE t_security_log (
    log_id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    uid BIGINT UNSIGNED,
    ip VARCHAR(45) NOT NULL,
    action VARCHAR(32) NOT NULL,
    status TINYINT NOT NULL,
    details TEXT,
    create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_uid (uid),
    INDEX idx_ip (ip),
    INDEX idx_action (action),
    INDEX idx_create_time (create_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 四、ELO 积分算法

```cpp
// 胜率期望
float Ea = 1.0f / (1.0f + pow(10.0f, (Rb - Ra) / 400.0f));

// 积分更新
Ra_new = Ra + K * (Sa - Ea);
// K = 32（新手），K = 24（中手），K = 16（高手）
// Sa = 1（胜），0.5（和），0（负）
```
